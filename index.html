Using a pack with packwiz

Give your packwiz-compatible launcher the pack's pack.toml URL. Use /create-aeronautics/pack.toml from this site. The packwiz installer will read the index and download the referenced files.

To add another pack, create another top-level directory and add its pack.toml URL to this page.

Pack files are updated automatically when changes are pushed to the main branch.
